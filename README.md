# BMC Motos — Site

Projeto inicial da BMC Motos para publicar no GitHub Pages.

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — visual do site
- `assets/js/app.js` — estoque, busca e WhatsApp
- `assets/img/` — coloque aqui as fotos das motos

## Antes de publicar

1. Abra `assets/js/app.js`.
2. Troque `5500000000000` pelo WhatsApp real da loja.
3. Edite a lista `bikes` com estoque, ano, km e preço.
4. Coloque as fotos em `assets/img/` e informe o caminho em `image`.

## Publicar no GitHub Pages

Crie um repositório, envie os arquivos e ative **Settings → Pages → Deploy from a branch → main → /(root)**. O GitHub Pages pode publicar sites estáticos diretamente de um repositório. 

Importante: não coloque senhas, tokens, dados de clientes, documentos ou outras informações privadas neste repositório público.

# Estrutura planejada da BMC Motos

## Fase 1 — Site público
- Home
- Estoque
- Busca de motos
- Botão WhatsApp
- Serviços
- Sobre a loja
- Contato
- Responsivo para celular

## Fase 2 — Sistema da loja
Sugestão de módulos futuros:
- Cadastro de motos
- Entrada/saída de estoque
- Custo de aquisição
- Preço de venda
- Margem de lucro
- Status: disponível, reservado, vendido, consignado
- Clientes
- Leads
- Test ride
- Financiamento
- Consignação
- Agenda
- Pós-venda
- Relatórios

## Fase 3 — Integrações
- Banco de dados
- Login administrativo
- Painel interno
- Upload de fotos
- WhatsApp
- Formulários
- Analytics

Não coloque dados pessoais ou financeiros de clientes no GitHub público.
